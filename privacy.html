Hindsight encrypted backups

Privacy policy

Effective date: 2026-09-16

This policy covers the personal Hindsight encrypted backups application operated by Ashrith Mekala and this informational website.

Data accessed and used

The application uses Google OAuth and the drive.file permission to create and manage its backup files and folders in the owner's Google Drive. It uploads encrypted archives, reads file metadata and checksums, downloads archives for recovery checks, and deletes older app-created backups. It does not request Drive-wide access.

Archives contain the owner's Hindsight database, which may include stored conversations and documents, and configuration needed to restore the service. The application uses these contents only for backup and recovery. Checksums, completion markers, file sizes, and backup timestamps may be stored outside the encrypted archive.

Storage and access

Archives are encrypted before upload. Encrypted copies are stored on the owner's server and in the owner's Google Drive. Google receives encrypted archives and backup metadata. The decryption key is kept separately from Google Drive. OAuth credentials and tokens are stored in private configuration files on the owner's devices. Temporary unencrypted files are used locally during backup and recovery.

The application does not sell Google user data, use it for advertising or model training, or share it with other users. Access is limited to the owner and the services necessary for authorization and storage. Its use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

The default settings keep local backups for 14 days and retain 7 daily, 4 weekly, and 3 monthly completed cloud copies. The owner can change these settings or delete backups directly. Copies saved separately for recovery remain until the owner deletes them.

The owner can revoke the application's access in Google Account connections. Revoking access stops future authorized access; existing backups must be deleted separately from Google Drive and local storage.

This website

These pages contain no analytics scripts, advertising, forms, or application cookies. GitHub Pages hosts the website and may process visitor information under the GitHub Privacy Statement. Backup files and credentials are not published here.
