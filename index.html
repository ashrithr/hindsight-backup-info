Hindsight encrypted backups

A personal backup application operated by Ashrith Mekala. It saves encrypted copies of a self-hosted Hindsight memory database and recovery configuration to the owner's Google Drive.

How it works

The application encrypts backup archives on the owner's server before uploading them. It uses Google Drive to store those archives and to download them for recovery checks. It removes older app-created backups according to the configured retention settings.

Google Drive access

The application requests https://www.googleapis.com/auth/drive.file. Its backup workflow manages files and folders it creates. It does not request access to all files in Google Drive.

This application is for the owner's personal use. There is no public sign-up or backup upload form. This website provides information only and does not connect to the backup service.

This is an independent personal project. It is not an official Hindsight or Google service.
